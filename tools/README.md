# Інструменти

Скрипти для роботи над сайтом. На сам сайт не впливають, `server.js`
цю теку назовні не віддає. Потрібен лише Windows PowerShell — жодних
установок.

**Скрипти навмисно без кирилиці.** PowerShell 5.1 читає `.ps1` як ANSI,
і українські літери всередині ламають розбір файлу.

## cutout.ps1 — зрізати фон з фото товару

Приводить студійний знімок на білому до формату каталогу: 640×640,
png з прозорістю, товар по центру з полями.

```
powershell -ExecutionPolicy Bypass -File tools\cutout.ps1 `
  -In "C:\Users\Bogdan\Downloads\IMG_1234.PNG" -Out "photo\vyrizka.png"
```

Що робить по кроках:

1. Заливкою від краю кадру стирає світлий фон. Від краю — щоб білі
   відблиски всередині товару лишилися на місці.
2. Окремим правилом прибирає мʼяку тінь: строго нейтральний сірий
   поряд із фоном. Їжа майже ніколи не буває такою знебарвленою.
3. Стирає замкнені острівці фону — дірку всередині кільцевої ковбаски,
   просвіт між шматками. Заливка від краю їх не дістає.
4. Підрощує фон усередину на кілька пікселів. Знімок на білому завжди
   має підсвічену кромку, і без цього вона світиться на темному тлі.
5. Обрізає по вмісту, вписує у квадрат і зберігає.

Корисні ключі:

| Ключ | За замовчуванням | Навіщо крутити |
|---|---|---|
| `-Erode` | 3 | Світла кайма лишилась — більше. Зʼїло деталі — менше. Для блідих товарів брали 6 |
| `-Soft` | 196 | Фон темніший за звичайний — знизити |
| `-Shadow` | 140 | Тінь лишається — знизити. Зникають сірі частини товару — підняти |
| `-Holes` | 0.08 | Відсоток кадру: менші острівці фону лишаються |
| `-Pad` | 24 | Поля навколо товару в підсумковому квадраті |

Не бере кольоровий чи строкатий фон — тільки білий і дуже світлий.

## audit.ps1 і edge.ps1 — перевірити результат

Не на око, а числом. Перед тим як класти фото в каталог, варто
порівняти нове зі старими.

```
powershell -ExecutionPolicy Bypass -Command ^
  "& '.\tools\edge.ps1' -Dir '.\photo' -Names @('vyrizka.png','oshyyok.png')"
```

`edge.ps1` міряє саму кромку: непрозорі пікселі, що межують із
прозорими. Це і є біла кайма. Орієнтир по каталогу: середня яскравість
30–110, частка блідих пікселів до 1%. Якщо помітно вище — підняти
`-Erode`.

`audit.ps1` міряє картинку цілком: скільки зайнято товаром, наскільки
він заповнює квадрат, скільки лишилось білих непрозорих пікселів.
Орієнтир: заповнення 30–57%, рамка вмісту 92–94%.

## serve.ps1 — підняти сайт локально

```
powershell -ExecutionPolicy Bypass -File tools\serve.ps1 -Root "." -Port 8777
```

Потрібен, бо сторінка підключає `catalog.js` тегом `<script>`: якщо
відкрити `index.html` подвійним кліком, файл не завантажиться і
каталог буде порожній. Роздає статику, `server.js` не запускає —
для бота й прийому замовлень потрібен Node.

### Чорний фон

Знімок на чорному ріжеться тим самим скриптом, з ключем `-Dark`:

```
powershell -ExecutionPolicy Bypass -File tools\cutout.ps1 `
  -In "kachka.jpg" -Out "photo\kachka-yabluka.png" -Dark
```

Логіка дзеркальна: фоном вважається нейтральний піксель, темніший за
`-DarkMax`. Дивимось на найяскравіший канал, щоб темно-червона глазур
на мʼясі не пішла у фон разом із тлом.

Правило про мʼяку тінь у цьому режимі не діє — на чорному її не видно.

### Формат вхідного файлу

Бере jpg, png і webp. Телефони часто віддають webp, а стандартний
механізм Windows його не відкриває: падає з «Out of memory», хоча файл
цілий. Скрипт тоді сам переходить на інший декодер.

**Текстурний фон не бере** — крафтовий папір, дерево, скатертина. Тільки
рівний білий або рівний чорний.

### Фон уже прибрано деінде

Крафтовий папір, дерево, скатертина — таке скрипт не бере. Такі знімки
проганяємо через сторонній сервіс видалення фону, а сюди приносимо
готовий png із прозорістю. Далі лишається тільки привести до формату:

```
powershell -ExecutionPolicy Bypass -File tools\cutout.ps1 `
  -In "gotove.png" -Out "photo\chevap-syr.png" -Keep
```

`-Keep` не чіпає прозорість узагалі, тільки обрізає по вмісту і вписує
у квадрат 640×640.

**Без цього ключа файл зіпсується.** Скрипт шукатиме білий фон, не
знайде його — під прозорими пікселями зазвичай чорний — і зробить їх
непрозорими. Перевірено на вирізці: заповнення підскочило з 57% до 86%,
навколо мʼяса зʼявився чорний квадрат.

### Відблиски й відображення

Глянцевий стіл дає під товаром відображення, мокра дошка — бризки.
Заливка їх не чіпає: вони не кольору фону. На сайті це читається як
бруд під стравою.

Ключ `-Specks` викидає окремі острівці збережених пікселів, менші за
вказаний відсоток кадру. За замовчуванням 0.05 — прибирає дрібні
цятки. Для сильного відображення доводиться піднімати:

```
powershell -ExecutionPolicy Bypass -File tools\cutout.ps1 `
  -In "kartoplya.png" -Out "photo\kartoplya-salo.png" `
  -Dark -DarkMax 26 -Holes 99 -Specks 2
```

Обережно: ключ викидає все дрібне й відокремлене. Якщо у страви є
деталь, що не торкається основної маси — гілочка, шматок гарніру
збоку, — вона теж зникне. Перевіряйте очима.

### Фольга, глянець та інше темне всередині товару

У фольги глибокі тіньові складки, і на чорному фоні вони теж
вважаються фоном. Оскільки вони замкнені, їх прибирає правило дірок —
і у фользі зʼявляються наскрізні отвори.

Лікується двома ключами: `-Holes 99` вимикає прибирання замкнених
островів, а `-DarkMax 26` звужує поняття «чорний» так, щоб складки
лишилися товаром.
