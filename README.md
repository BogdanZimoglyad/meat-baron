# Мʼясний Барон — сайт + Telegram-бот

## Структура
```
meat-baron/
├── index.html      ← увесь сайт: верстка, каталог, кошик, оформлення
├── sw.js           ← service worker (офлайн і кеш)
├── manifest.json   ← PWA
├── photo/          ← фото товарів
├── server.js       ← API прийому замовлень + Telegram-бот
├── package.json
└── data/           ← база замовлень, у git не потрапляє
```

Сайт лежить **у корені**. Другої копії немає — це навмисно.
Раніше поруч була тека `public/` з окремим `index.html`, і дві версії
розійшлися: GitHub Pages віддавав свіжу, а сервер — стару.

## Два деплої, один код

| Що | Звідки | Що робить |
|---|---|---|
| GitHub Pages | корінь гілки `main` | сайт для клієнтів |
| Railway | той самий корінь через `server.js` | API, Telegram-бот, дзеркало сайту |

`server.js` роздає корінь репозиторію і ховає службові файли
(`server.js`, `package.json`, `data/`, `node_modules/`) — вони віддають 404.

У браузері адреса API задана в `index.html`:
```js
const API='https://meat-baron-production.up.railway.app';
```
Абсолютна адреса потрібна, бо з GitHub Pages запит іде на інший домен.
З самого Railway вона теж працює — це його ж домен.

## Запуск

1. Створити бота: у Telegram написати **@BotFather** → `/newbot` → скопіювати токен.

2. Встановити і запустити:
```
npm install
BOT_TOKEN=ваш_токен node server.js
```

3. Для кожної точки створити групу в Telegram, додати бота і операторів,
   у групі надіслати:
```
/points      — список точок
/bind 1      — прив'язати чат до точки №1
/whoami      — перевірити прив'язку
```

4. Відкрити сайт: http://localhost:3000

## Як працює
- Клієнт оформлює замовлення → воно летить у чат своєї точки
- Оператор тисне кнопки: Прийняти → Готується → Готове → Видано
- Сайт клієнта оновлює статус кожні 15 секунд
- На статусі «Готове» відправляється SMS (поки що лише лог у консолі)

## PWA
Сайт встановлюється на телефон як застосунок:
- Android: зʼявляється банер «Додати на екран»
- iPhone: Safari → «Поділитися» → «На екран Додому»

Працює лише через HTTPS (на Railway/Render він увімкнений автоматично).

## Що треба доробити
- SMS: підключити TurboSMS у функції `sendSms()` в `server.js`
- Онлайн-оплата: LiqPay або Fondy
- Фото товарів замість заглушок
