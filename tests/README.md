# Тести

```
npm test          # правила й сервер (vitest), ~1 с
npm run cover     # те саме з покриттям server.js і catalog.js
npm run ui        # сайт, панель, статистика в браузері (Playwright), ~30 с
```

Перед першим `npm run ui` на новому компʼютері: `npx playwright install chromium`.

GitHub Actions ганяє обидва набори на кожен PR і кожне вливання в
`main` — біля PR видно ✅ або ❌. Покриття нижче 50% — теж ❌: нові
правила без тестів непомітно не проходять. Упав тест у браузері —
звіт зі знімками екрана лежить у запуску Actions → Artifacts.

**Правило (власник, 01.10.2026):** нова можливість — тест основного
шляху; виправлена помилка — тест, що її ловить. Поки червоне — у `main`
не вливаємо.

## Що де

**`unit/`** — окремі правила. Не копія логіки, а справжній код: тест
вирізає функції з `server.js`, `index.html` чи `op.html` регулярним
виразом і ганяє на підставлених даних. Перейменували функцію — тест
одразу падає з «не знайшли», розійтися з бойовим кодом він не може.

| Файл | Що накриває |
|---|---|
| `shop.test.js` | стоп-лист і мангал: `applyStock`, `applyGrill`, стан для панелі |
| `panel.test.js` | розмітка картки в `op.html`: які кнопки побачить оператор у кожному статусі |
| `pickup.test.js` | нагадування про незабране замовлення |
| `stats.test.js` | підсумки `/week` і `/month` |
| `stop.test.js` | пошук позицій і поведінка сайту, коли позиції немає |
| `backup.test.js` | щоденна копія бази |
| `a2hs.test.js` | кому і коли показуємо «Додайте на екран» на айфонах |
| `push.test.js` | сповіщення в браузер: список пристроїв, протухлі підписки, тексти |
| `line.test.js` | правки складу замовлення: ціни, межі, смаження, доставка |
| `time.test.js` | перенесення часу замовлення: київський час, години точки, мангал |
| `nag.test.js` | голосові нагадування панелі: коли заговорить, як часто, що скаже |
| `statspage.test.js` | сторінка статистики власника: підсумки, дні, позиції, клієнти, воронка |
| `kassa.test.js` | розбір відповіді оператора з цифрами каси |
| `sms.test.js` | SMS через TurboSMS: коли шлемо, тексти, помилки |

**`api/`** — справжній `server.js` із підставним Telegram-ботом і
тимчасовою базою (`harness.js`). Тест ходить по адресах, як сайт, панель
і статистика, тисне кнопки в чаті й «ділиться номером», як покупець. В
інтернет нічого не шле.

| Файл | Що накриває |
|---|---|
| `flow.test.js` | шлях замовлення: вхід через Telegram → замовлення → картка в чаті → панель (статуси, 🧾, ➕/➖, 🕒) → сповіщення покупцю; доставка з 🚕 і «отримав»; скасування з причиною; стоп-лист і мангал; /panel-off |
| `server.test.js` | лічильник відвідувань, доступ до статистики, цифри каси, /panel, /day без тестових |

**`ui/`** — справжній браузер (Chromium) на тому самому server.js з
підставним ботом (`serve.js`). Сайт — на екрані телефона (Pixel 7),
панель і статистика — на планшеті 1280×800. Адресу
`api.meat-baron.kh.ua` в сторінках підміняємо на локальний сервер, усе
стороннє відрізане: живу базу й Telegram тест не чіпає. Поруч із
сервером — «пульт» за Telegram: тест пише `/panel` у чат точки, тисне
кнопки, «ділиться номером», як покупець.

| Файл | Що накриває |
|---|---|
| `site.spec.js` | гість: картка → вага → кошик (+, прибрати) → оформлення → картка в чаті точки → сторінка сама бачить «Прийнято»; вхід через Telegram; доставка без адреси не проходить |
| `panel.spec.js` | оператор: «Нове» → 🧾 сума з комою → ➕ позиція → «Видано»; скасування з причиною; стоп-лист одразу ховає позицію на сайті; мангал; чуже посилання не відкриває панель |
| `stats.spec.js` | власник: плитки збігаються з сервером, тестові — лише в списку зі значком ТЕСТ; без посилання не відкривається |

Кожен тест приходить зі своєї адреси (`X-Forwarded-For`): сервер
приймає не більше 5 замовлень з однієї адреси за кілька хвилин.

Старі перевірки складали результати в список `[назва, пройшло?]`;
`report.js` робить із кожного рядка окремий тест vitest із тією самою
назвою. Нові можна писати так само або звичайним `test()`.

Тести не залежать від часового поясу комп'ютера: на GitHub і Railway
стоїть UTC, а точка живе за Києвом. Перевірено в UTC, Нью-Йорку й Києві.
